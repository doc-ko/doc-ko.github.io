= Personal Site Docs
:description: Owner documentation for maintaining and customising the personal website.

This documentation is the owner guide for the `{site-domain}` website.
It explains what changed in the current branch and how to make future edits without rediscovering the Astro project structure.

* xref:customising-the-site.adoc[Customising the site]: a practical walkthrough for editing copy, links, pages, and visual styling.

== Useful Commands

Run these from the repository root.

[source,sh]
----
npm install
npm run dev
npm run build
----

`npm run dev` starts the local Astro development server.
`npm run build` checks that the site can be generated for production.

== Mental Model

This is a small Astro site.
Most pages live under `src/pages/`, shared layout and interface pieces live under `src/components/` and `src/layouts/`, and the main visual system lives in `src/styles/global.css`.

For routine homepage copy changes, start with `src/data/homepage.yaml` before editing component markup.
